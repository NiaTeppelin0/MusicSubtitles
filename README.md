## 🌟 Возможности мода

### 🎧 Совместное прослушивание (Music Sync)
* **Синхронизация между игроками:** Слушайте любимые треки вместе с друзьями на любых серверах через ультрабыстрый релей.
* **Приватные комнаты:** 5-значные коды подключения, возможность задать пароль или создать открытую комнату.
* **Модерация хоста:** Кик и бан нежелательных слушателей прямо из графического интерфейса комнаты.
* **Защита от подбора:** Автоматический rate-limiting неверных кодов (блокировка на 30 секунд после 5 неудачных попыток).
* **Живая диагностика:** Контроль рассинхрона в миллисекундах, режим сглаживания *Acoustic Micro-Glide* (плавная подстройка скорости без щелчков и артефактов перемотки) и мониторинг сетевого пинга.

### ✨ Режимы отображения субтитров
* **3D в мире:** Текст песни парит в трёхмерном пространстве перед персонажем, плавно поворачиваясь за камерой.
* **На блоке:** Проекция слов прямо на поверхность блоков в мире игры.
* **2D экран:** Классический стильный рендеринг поверх интерфейса.
* **2D разброс:** Динамическое появление слов в разных точках экрана с анимацией затухания.
* **В чате:** Текстовые строчки прямо в чате Minecraft.
* **Караоке в карточке HUD:** Посимвольная подсветка поющегося текста прямо внутри плашки трека.
* **Smart Sprint Delay:** При остановке во время бега динамический режим субтитров мягко ждёт 1 секунду перед сбросом, предотвращая дергание текста.

### 🎨 Modern Glassmorphic UI
* Неоновый тёмный стиль (`#00F5D4`), плавные переходы фокуса и динамическая подсветка.
* Идеальное центрирование текста и курсора во всех полях ввода.
* Адаптивные карточки подсказок (Tooltips), исключающие обрезание текста по краям.
* Круговое радиальное меню (`R`) с 32-полосным спектроанализатором вокруг винила.
* Встроенный редактор таймингов и стилей субтитров (`/musicsubtitles editor`).

### 🔌 Источники музыки и интеграции
* **Плееры и стриминги:** Яндекс Музыка (нативный OAuth API), Spotify, YouTube Music, VK Музыка, SoundCloud, Deezer, локальные аудиофайлы (MP3, WAV, FLAC).
* **Поиск текстов и Live-STT:** Автоматический поиск таймингов через LRCLIB, Яндекс Музыку, Kugou, QQ Music, NetEase и Genius; если текст не найден — потоковая генерация субтитров на лету из системного аудио (WASAPI loopback + вокальный bandpass 180–4200 Гц + Speech-to-Text + караоке-тайминги).
* **Стриминг-алерты:** Twitch (фолловеры, подписки, донаты) и DonationAlerts.
* **Smart Ducking:** Умное приглушение звуков мобов и окружения во время музыки.

## 🚀 Установка

1. Установите **Minecraft 1.21.11** (или совместимую версию 1.21.x).
2. Установите **Fabric Loader** версии `0.16.9` или выше.
3. Поместите **Fabric API** в папку `.minecraft/mods/`.
4. Скачайте файл **`MusicSubtitles-2.8.1.jar`** из раздела Releases и переместите в `.minecraft/mods/`.
5. Запустите Minecraft. Мод готов к работе!

## ⌨ Горячие клавиши

| Клавиша | Действие |
|:---:|---|
| <kbd>R</kbd> | Открыть радиальное меню быстрого доступа (Radial Menu) |
| <kbd>K</kbd> | Добавить текущий играющий трек в «Избранное» |
| <kbd>J</kbd> | Открыть библиотеку треков и список сохранённого избранного |
| <kbd>H</kbd> | Переключить режим отображения субтитров |
| <kbd>M</kbd> | Быстрый переход в меню совместного прослушивания |

## 💬 Команды

| Команда | Описание |
|---|---|
| `/musicsubtitles` | Открыть главное конфигурационное меню мода |
| `/musicsubtitles room` | Открыть окно совместного прослушивания (Music Sync) |
| `/musicsubtitles diag` | Запустить глубокую диагностику системы и сети |
| `/musicsubtitles editor` | Открыть визуальный редактор субтитров |
| `/musicsubtitles reload` | Перезагрузить текущий трек и текст |
| `/musicsubtitles cancel` | Отключить субтитры для текущего трека |
